# Store Assets

This directory contains assets for app store listings (Google Play Store, Apple App Store).

## Required Assets

### Feature Graphic (Google Play)
- **File:** `feature-graphic.png`
- **Dimensions:** 1024 x 500 px
- **Format:** PNG (24-bit) or JPEG
- **No transparency**

### Screenshots (Phone)
- **Files:** `screenshot-1.png` through `screenshot-5.png`
- **Dimensions:** 1080 x 1920 px (portrait) or 1920 x 1080 px (landscape)
- **Format:** PNG (24-bit) or JPEG
- **Min:** 2 screenshots, **Max:** 8 screenshots

### Screenshots (7-inch Tablet)
- **Files:** `tablet-screenshot-1.png` through `tablet-screenshot-5.png`
- **Dimensions:** 1200 x 1920 px (portrait) or 1920 x 1200 px (landscape)
- **Format:** PNG (24-bit) or JPEG

### High-res Icon (Google Play)
- **File:** `high-res-icon.png`
- **Dimensions:** 512 x 512 px
- **Format:** PNG (32-bit with alpha)

### Promo Graphic (Google Play - Optional)
- **File:** `promo-graphic.png`
- **Dimensions:** 180 x 120 px
- **Format:** PNG (24-bit)

### App Preview Video (Optional)
- **File:** `preview-video.mp4` or `.mov`
- **Duration:** 30 seconds max
- **Aspect ratio:** 16:9 (landscape) or 9:16 (portrait)

## Screenshot Content Guidelines

1. **Screenshot 1:** Home/Onboarding - show the persona selection screen
2. **Screenshot 2:** Chat screen with Best Friend persona
3. **Screenshot 3:** Chat with Girlfriend persona (show premium badge)
3. **Screenshot 4:** Settings/Profile screen showing subscription tier
4. **Screenshot 5:** Memory/Persona settings or Notifications screen

## Creation Notes

- Use a test device or emulator at 1080x1920 (phone) or 1200x1920 (tablet)
- Set device to dark/light mode as appropriate for the app theme
- Capture screenshots that showcase the app's key features
- Ensure no sensitive/test data is visible
- Use the latest app version with all features enabled
